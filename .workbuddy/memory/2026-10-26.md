### 绿色包的硬规矩：不能只拷 exe
- `plugins/*.uploader.json` 是 exe **外部**资源，靠 `app.path().resource_dir()` 定位；
  Windows 上 resource_dir 恒等于 exe 所在目录（tauri-utils platform.rs 里
  `if cfg!(target_os = "windows") { return exe_dir }`）
- 只拷 exe：`state.paths.builtin_plugins` 回退到 `%APPDATA%\...\builtin-plugins`（不存在）
  → `read_dir` 失败 → 加载逻辑 `continue`，**完全静默**，插件页里内置图床凭空消失
- 验证办法：`SNIPFORGE_LOG=debug` 看日志有没有「声明式图床 xxx 已禁用，跳过」——
  能打出来就说明目录读到了、JSON 解析成功了（这两个插件在用户配置里是 disabled 状态，
  所以「加载声明式图床 0 个」是正常的，别误判成打包坏了）
